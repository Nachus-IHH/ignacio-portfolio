# Ignacio Hernández — Portafolio personal

Sitio estático responsive construido con HTML, CSS y JavaScript vanilla. No requiere instalación ni proceso de compilación.

## Ejecutar localmente
Abre `index.html` en un navegador. Para un entorno local más consistente puedes ejecutar:
```bash
python -m http.server 8000
```
y visitar `http://localhost:8000`.

## Personalización antes de publicar
Busca en `index.html` los placeholders:
- `TU_CORREO@EJEMPLO.COM`
- enlaces `href="#"` de GitHub y LinkedIn

Añade los enlaces reales a repositorios y demos cuando estén disponibles. Los proyectos están descritos únicamente con la información proporcionada; no se añadieron métricas ni responsabilidades no confirmadas.

## Fotografía
`assets/ignacio-portrait.jpg` es un recorte de la segunda imagen que compartiste, usado como retrato principal. Puedes reemplazarlo conservando el mismo nombre de archivo.

## CV en PDF
El botón “Guardar como PDF” abre la función de impresión del navegador. Selecciona “Guardar como PDF”. Para un resultado más limpio, desactiva encabezados y pies de página del navegador.

## Despliegue
Puedes publicar la carpeta completa en GitHub Pages, Netlify, Vercel o cualquier hosting estático.
